## 真實取得問題與解法
1. 初次 Python 網路請求受 sandbox 網路限制；使用可用的網路權限設定後取得內容，未繞過付費或登入限制。
2. C04 的網頁 PDF 按鈕未直接開啟檔案。從原網頁 citation_pdf_url 找到官方下載入口；網頁工具無法處理其 octet-stream 類型，Python 取得 PDF，驗證檔頭、455099 bytes、10 頁及可讀文字。定位 §5–6 與 p.1274 結論，正式匯入，不只摘要。
3. C05 Python 回應只有 212 bytes，實為驗證頁；網頁閱讀工具已成功取得正文。初次結構檢查捕捉小檔案問題，修正 manifest 取得狀態，保留原回應雜湊並註明不是正文版本雜湊。不宣稱保存完整原文快照。
4. 想用 BeautifulSoup 查網頁日期時發現未安裝 bs4；改用標準函式庫讀取必要欄位，沒有安裝套件。C05 未核定日期記 n.d.。
