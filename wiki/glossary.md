# 術語表

| 詞彙 | 本 Wiki 用法 | 依據 |
|---|---|---|
| 注意力限制 | 同一時間處理能力有限，不能直接換算通用秒數 | [K01](claims.md) |
| 選擇性注意力 selective attention | 優先處理部分資訊、忽略干擾 | [K02](claims.md) |
| 非注意盲視 inattentional blindness | 注意投入別處時，未察覺可見物件；本文統一用此譯名，來源亦作不注意視盲 | [C01 Vocabulary](../sources/notes/C01.md)、[K05](claims.md) |
| 分散注意力 divided attention | 在兩項以上同時進行的任務間配置注意 | [K07](claims.md) |
| 多工 multitasking | 可涵蓋同時做與交替做，使用時須說明是哪一種 | [K08](claims.md) |
| 任務切換 task switching | 從某任務改為另一任務 | [K09](claims.md) |
| 切換成本 switch cost | 相對重複／持續任務，切換所增加的表現代價 | [K09](claims.md) |
| Stroop 效應 | 色字干擾的典型現象，必須說清楚反應規則與比較基準 | [K10、K12](claims.md) |
| 自動化加工 automatic processing | 不宜直接等同完全無需注意力；須看任務條件 | [K11](claims.md) |

## v3 補充術語（首次出現附英文）

| 名詞 | 入門用法與依據 |
|---|---|
| 注意力 attention | 對資訊的選擇與處理涉及有限能力；見01-basics及[1] What is Attention?。 |
| 雙重任務 dual task | 兩項任務同時進行的教學／研究安排；須分別比較兩項任務單獨與同時的表現，並非「被打斷」的同義詞。見03-multitasking及[1] Divided Attention Tasks。 |
| 自動化加工 automatic processing | 有些熟練處理不必每一步都刻意指揮便容易啟動，但仍受條件調節。見[處理頁](processing.md)，不定義為絕對無需注意。 |
| Stroop效應 Stroop effect | 色字衝突可能干擾墨色反應；需交代比較基準。見04-stroop及[研究起源](06-research-origins.md)。 |
| 雙耳分聽 dichotic listening | 兩耳接收不同訊息、常要求跟讀其中一耳的作業。見[補充研究](07-related-experiments.md)。 |
| 雞尾酒會效應 cocktail party effect | 複雜聲音中跟隨特定對話的現象，某些有意義線索仍可能吸引注意。見[補充研究](07-related-experiments.md)。 |

本節編號詳見[來源表](sources.md)。分散注意力仍統一用 divided attention，多工為 multitasking，任務切換為 task switching，切換成本為 switch cost；同詞不任意換譯。
